**Kort om hur du använder Jeeves online-dokumentation**

En detaljerad beskrivning finns i kapitlet: [Introduktion till online-dokumentationen](ms-its:DocAreas_sw.chm::/Doc_1502.htm).  
  
Observera att alla bilder och beskrivningar avser Jeeves Application services (JAS). Observera också att funktions- och flödesbeskrivningarna är främst avsedda för verksamhetskonsulter och systemadministratörer. Det finns separata användarmanualer för slutanvändare.

|  |  |  |
| --- | --- | --- |
|  | Flik | Användningsområde |
| Sök | Innehåll/Contents | Sortera dokumentationen per manual, applikation och rutin. |
|  | Sök/Search | Slå upp ord och fraser med fritextsökning. Tips! Sök efter en specifik fras inom dubbla frågetecken. Sortera sedan genom att klicka på "Location". |
|  | Bokmärken/Favorites | Spara länkar till viktiga kapitel. |
