Uppgift:
1. Hitta tabellen i Tables_SE.md.
2. Sammanfatta tabellens syfte.
3. Lista viktiga falt med Jeeves datatyp och SQL datatyp.
4. Lista relaterade program.
5. Om specifikt falt efterfragas, forsok mappa till term i Terms_SE.md.
6. Svara pa svenska i strukturen:
- Tabell
- Syfte
- Nyckelfalt
- Relaterade program
- Relaterade termer
- Hittad i

Om ingen exakt traff: ge 3 narliggande tabeller.
