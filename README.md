# ERP-Jeeves-AI-Skills

En samling av AI-drivna färdigheter och integrationer för **Jeeves ERP-system** utvecklad av Dizparc Värnamo.

## 📋 Beskrivning

Detta projekt innehåller utveckling och implementering av artificiell intelligens-baserade verktyg och integrationspunkter för Jeeves ERP-system. Projektet möjliggör automation och intelligenta lösningar för affärskritiska processer.

### Huvudsakliga Komponenter

- **Claude Code**: AI-baserad kodgenerering och kodanalys för Jeeves ERP
- **claudeai-skill**: Färdighet-modul för Claude AI-integration
- **jeeves-copilot**: Copilot-lösning för assisterad arbetsflöde i Jeeves ERP

## 📁 Projektstruktur

```
ERP-Jeeves-AI-Skills/
├── Claude Code/              # Kodgenererings- och analyslösning
├── claudeai-skill/           # Claude AI-färdighetsmodul
├── jeeves-copilot/           # Jeeves Copilot-integration
├── Claude Code.zip           # Arkiverad Claude Code-modul
├── claudeai-skill.zip        # Arkiverad claudeai-skill
├── jeeves-copilot.zip        # Arkiverad jeeves-copilot
└── .gitattributes            # Git-konfiguration
```

## 🚀 Funktionalitet

### Claude Code
Möjliggör AI-assisterad kodgenerering och kodanalys direkt inom Jeeves ERP-miljön.

### Claude AI Skill
En färdighets-modul som utökar Jeeves med Claude AI-funktionalitet för intelligenta automatiseringar.

### Jeeves Copilot
En copilot-lösning som ger användarstöd och automatisering för vanliga arbetsflöden i Jeeves ERP-systemet.

## 🛠️ Teknologi

- **Språk**: Python
- **Plattform**: Jeeves ERP System
- **AI-Integration**: Claude AI, GitHub Copilot

## 📝 Användning

Varje modul (`Claude Code`, `claudeai-skill`, `jeeves-copilot`) kan användas separat eller tillsammans för att:

1. Automatisera repeaterande uppgifter
2. Generera och analysera kod
3. Assistera användare med intelligenta förslag
4. Optimera affärsprocesser

## 📦 Installation

För att använda dessa färdigheter:

1. Extrahera relevant `.zip`-fil från repository
2. Följ installationsinstruktioner i respektive modul
3. Konfigurera integrationsinställningar för din Jeeves ERP-miljö
